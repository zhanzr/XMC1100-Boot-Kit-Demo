# LCM2004 4bit GPIO driver(MDK5 ARMCLANG 6)

VO contrast adjustment is driven by a CCU4 PWM channel.

## LCM-S02004DSR
VO	<->	P0.3
RS	<->	P0.0
RW	<->	GND
E	<-> P0.2
DB4	<->	P0.9
DB5	<->	P1.1
DB6	<->	P1.0
DB7	<->	P0.8

## LED
LD0	<->	P0.7
LD1	<->	P0.5
LD2	<->	P0.6
LD2_1	<->	P1.2
LD2_2	<->	P1.3
LD3	<->	P1.4
LD4	<->	P1.5

## UART
TX	<->	P1.2
RX	<->	P1.3
